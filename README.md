# JARVIS Onboarding Kit

> ⚠️ **PRIVATE — contains internal SOPs. Never enable Pages. Never share docs 03/05/06/07 with clients.**

Client onboarding kit for the **JARVIS Agent install service** (Just Jarvis LLC). A set of
9 self-contained HTML documents that walk a new client from intake through install, handoff,
and follow-up — plus the internal SOPs the team uses to deliver the install.

Every file is a standalone HTML doc (no build step, no external assets). Open `index.html`
in a browser as the entry point.

## Documents

| Doc | File | Audience | Description |
|-----|------|----------|-------------|
| — | `index.html` | Client-facing | Landing page / table of contents linking every doc in the kit. |
| 00 | `00-README.html` | Client-facing | Kit overview — what the kit is and how to use it. |
| 01 | `01-client-intake-form.html` | Client-facing | Client intake form to capture requirements before the install. |
| 02 | `02-pre-install-access-checklist.html` | Client-facing | Pre-install access checklist of credentials/access the client must provide. |
| 03 | `03-team-install-sop.html` | **Internal** | Team install SOP — step-by-step procedure the team follows to install. |
| 04 | `04-client-handoff-playbook.html` | Client-facing | Owner's playbook handed to the client at handoff. |
| 05 | `05-install-tracker-qa.html` | **Internal** | Install tracker & QA checklist used during delivery. |
| 06 | `06-followup-support.html` | **Internal** | Follow-up & support runbook for post-install care. |
| 07 | `07-email-templates.html` | **Internal** | Email sequence templates for client communication. |

## Client-facing vs. internal

- **Client-facing:** `index.html`, `00-README.html`, `01-client-intake-form.html`,
  `02-pre-install-access-checklist.html`, `04-client-handoff-playbook.html`.
- **Internal only (never share with clients):** `03-team-install-sop.html`,
  `05-install-tracker-qa.html`, `06-followup-support.html`, `07-email-templates.html`.

## Guardrails

- This repository is **private** and must stay private.
