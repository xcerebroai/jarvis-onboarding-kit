DOC 10Technical Setup — No Business Prep Required

Hermes · Claude · Telegram
Start to Finish

Pure plumbing — every command, code, and screen in one page. No intake form, no knowledge base, no CRM. Just a working agent answering on Telegram.

THE WHOLE JOB: Prereqs → Install Hermes → Claude key → Telegram bot → Wire it → Test → Auto-start
~45–60 minutes on a clean machine. Every command and code you need is on this page.
STEP 1

Prerequisites

MacCmd+Space → terminal → Enter  ·  WindowsStart → powershell → Enter

node --version
python3 --version     # Mac
python --version      # Windows

Need Node v18+, Python 3.10+.

  • Node missing → nodejs.org → LTS installer, defaults
  • Python missing (Windows) → python.org → tick "Add Python to PATH" on the first screen
  • Mac dev-tools popup → Install (brings Git). No popup: xcode-select --install
  • Windows: don't pre-install Git — the installer pulls it

Network check (do not skip):

curl -I https://api.telegram.org

HTTP response = clear. Hangs/redirect = network blocks Telegram → do the whole setup on a phone hotspot; fix the network after.

STEP 2
✅
Healthy first run prints the "Hermes Gateway Starting… Messaging platforms + cron scheduler" box. "Provider not configured" complaints are the to-do list, not errors.

Install Hermes

  1. Run the Hermes Desktop installer → let the "11 steps" prerequisites phase finish untouched (Mac: accept the dev-tools dialog if it stalls at 0/11)
  2. Close the shell. Open a FRESH one. Then:
hermes --version

Version banner = installed. Then:

hermes gateway
✅
Healthy first run prints the "Hermes Gateway Starting… Messaging platforms + cron scheduler" box. "Provider not configured" complaints are the to-do list, not errors.
STEP 3

Get the Claude API key

In the browser (nothing installs — Claude is a key, not a program):

  1. console.anthropic.com → sign up (separate from claude.ai chat — a chat subscription does NOT include API)
  2. Billing → add card → buy starter credits ($5–25)
  3. Settings → Limits → set the monthly spend limit — before creating any key
  4. API Keys → Create Key → copy with the Copy button (never drag-select — stray spaces break keys)

The key looks like: sk-ant-api03-xxxxxxxx... — shown ONCE. Save it in a password manager immediately.

STEP 4

Connect Claude in Hermes

  1. Hermes provider screen → click "I have an API key" (bottom of the screen)
  2. Paste the key
⛔
Two traps: (1) NEVER click "Sign in with Anthropic OAuth" or run claude setup-token — wrong billing path. Cancel any popup mentioning OAuth. (2) VERIFY THE SLOT — the key must sit in the Anthropic row; the OpenRouter row must be EMPTY. The dialog has dropped keys into OpenRouter before.
  1. Pin the model to Sonnet (bottom-right selector — if it says Opus, switch; Opus ≈ 5× cost)
  2. Gateway status bottom-left should read ready

Error decoder: "authentication failed" = wrong slot / bad paste · "no usable credit" = account unfunded or key from a different account (key + money + account must match) · error mentions "OpenRouter" = trash the OpenRouter entry entirely, select Anthropic, restart

STEP 5

Create the Telegram bot

On the phone:

  1. Telegram search → @BotFather (verified check — clones exist) → send:
/newbot
  1. Display name → any name · Username → must end in bot (e.g. MyAgentBot)
  2. BotFather returns the bot token:
1234567890:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Save it. Never post it in screenshots or group chats. 4. Tap START on the new bot — bots can't speak first

Get the numeric user ID (needed for the allowlist — it's a number, not the @username): - Message @userinfobot (exact handle, verified) → Start → copy the Id: number - Fallback: message your own bot once, then open in a browser:

https://api.telegram.org/bot<TOKEN>/getUpdates

→ find "from":{"id": → that number is you - Lost the bot later? BotFather → /mybots → tap the bot → tap its @username

STEP 6

Wire Telegram in Hermes

Hermes → Messaging → Telegram:

  1. Bot token → paste
  2. Allowed Telegram user IDs → the numeric ID (comma-separate multiple people)
  3. Allow all users → false / empty. Always. An open bot is anyone burning your API money
  4. Home channel ID → same user ID (lets the agent send scheduled messages/alerts on its own)
  5. Save changes → fully restart Hermes if status looks stale (quit from system tray too)

Make it survive reboots

  • WindowsPowerShell as Administrator →

(without admin it silently falls back to a fragile Startup-folder script) - Machermes gateway --help → service/install option - Final proof: reboot the machine → bot answers with no app opened manually
