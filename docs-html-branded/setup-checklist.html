Step 1

Prerequisites & network check

Open Terminal (Mac) or PowerShell (Windows) first.

How to do this step

Open a terminal: Mac — Cmd+Space → type terminal → Enter. Windows — Start → type powershell → Enter.

Run each line and read the result:

node --version # need v18+ python3 --version # Mac — need 3.10+ python --version # Windows curl -I https://api.telegram.org # a response = clear · hangs = blocked → use a phone hotspot

If something's missing: Node → install the LTS build from nodejs.org (accept defaults). Python on Windows → python.org, and tick "Add Python to PATH" during install. Mac dev-tools popup → click Install (this also brings Git); no popup → run xcode-select --install. On Windows, don't pre-install Git.

  • Node v18+ installed (node --version) — if missing, install LTS from nodejs.org
  • Python 3.10+ installed (python3 --version / python --version) — on Windows tick "Add Python to PATH"
  • Telegram reachable (curl -I https://api.telegram.org) — if it hangs, switch to a phone hotspot
  • Git available (Mac: accept the dev-tools popup; Windows: don't pre-install Git)
Step 2

Install Hermes

How to do this step
  1. Run the Hermes installer and let the "11 steps" finish untouched. (Mac: if it's stuck at 0/11, accept the hidden dev-tools dialog behind the window.)
  2. Close the shell completely, then open a FRESH one — the new commands only exist in a new window.

Then verify:

hermes --version hermes gateway

Healthy = a version banner plus the "Hermes Gateway Starting… Messaging platforms + cron scheduler" box. Seeing "Provider not configured" is just the to-do list — not an error.

  • Ran the Hermes installer and let the "11 steps" finish untouched
  • Closed the shell and opened a fresh one
  • hermes --version shows a version banner
  • hermes gateway shows the "Gateway Starting…" box (a healthy start)
Step 3

Claude API key

In the browser — nothing installs here.

How to do this step
  1. Go to console.anthropic.com and sign up. (This is the developer console — it's separate from the claude.ai chat site.)
  2. Open Billing → add a card → buy starter credits ($5–25).

  4. API Keys → Create Key → copy it with the Copy button. It looks like sk-ant-api03-… and is shown only once — paste it somewhere safe immediately.

Step 5

Create the Telegram bot

On your phone.

How to do this step
  1. In Telegram search, open @BotFather (the verified one — clones exist) and send /newbot.
  2. Set the display name = your business brand. Set the username — it must end in bot.
  3. Save the token it gives back (looks like 1234567890:AAE…) — never put it in screenshots or group chats.
  4. Tap START on your new bot — bots can't message you first.

Get your numeric user ID (a number, not your @username): message @userinfobot → Start → copy the Id: value. Fallback: message your own bot, then open https://api.telegram.org/bot<TOKEN>/getUpdates and find "from":{"id":. Lost the bot later? BotFather → /mybots.

  • Messaged the verified @BotFather and sent /newbot
  • Set a display name (business brand) and a username ending in bot
  • Saved the bot token (kept out of screenshots / group chats)
  • Tapped START on the new bot
  • Got your numeric user ID from @userinfobot
Step 6

Wire Telegram in Hermes

How to do this step

In Hermes, go to Messaging → Telegram:

  1. Paste the bot token.
  2. Allowed Telegram user IDs → enter your numeric ID(s), comma-separated.
  3. Allow all users = false / empty. Always. (Otherwise anyone who finds the bot can run it.)
  4. Home channel ID = the same numeric user ID — this lets the agent send you alerts and run scheduled tasks.
  5. Save. If the status looks stale, fully quit Hermes (including the system-tray icon) and reopen.
  • Pasted the bot token (Messaging → Telegram)
  • Added your numeric ID to Allowed Telegram user IDs
  • Allow all users = false/empty
  • Set Home channel ID = your user ID, then Saved
