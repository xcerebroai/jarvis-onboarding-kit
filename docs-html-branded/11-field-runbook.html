AI Agent Field Runbook

Telegram, Hermes, Claude, the wholesale knowledge base, and every prompt to paste — from empty machine to a live agent qualifying leads. Eleven steps.

THE WHOLE JOB: Prereqs → Hermes → Claude key → Telegram bot → Wire → First contact → Load the KB → Lock operator values → Run it
~60–90 min on a clean machine. Every command and every prompt to paste is on this page.
STEP 1

Prerequisites + network check

MacCmd+Space → terminal → Enter  ·  WindowsStart → powershell → Enter

node --version                      # need v18+
python3 --version                   # Mac — need 3.10+
python --version                    # Windows
curl -I https://api.telegram.org    # HTTP response = clear · hangs = blocked → use phone hotspot
  • Node missing → nodejs.org → LTS, defaults · Python missing (Win) → python.org, tick "Add Python to PATH"
  • Mac dev-tools popup → Install (brings Git). No popup: xcode-select --install · Windows: don't pre-install Git
STEP 2

Install Hermes

  1. Run the Hermes installer → let the "11 steps" finish untouched (Mac: accept the hidden dev-tools dialog if stuck at 0/11)
  2. Close the shell. Open a FRESH one. Then:
hermes --version
hermes gateway
✅
Healthy = version banner + the "Hermes Gateway Starting… Messaging platforms + cron scheduler" box. "Provider not configured" = the to-do list, not an error.
STEP 3

Claude API key (browser — nothing installs)

  1. console.anthropic.com → sign up (separate from claude.ai chat)
  2. Billing → card → starter credits ($5–25)
  3. Settings → Limits → SET THE MONTHLY SPEND LIMIT — before any key exists
  4. API Keys → Create Key → copy with the Copy button. Format sk-ant-api03-... — shown ONCE, save immediately
STEP 4

Connect Claude in Hermes

  1. Provider screen → "I have an API key" → paste
⛔
TWO TRAPS: never click "Sign in with Anthropic OAuth" / never run claude setup-token (wrong billing path — Cancel any OAuth popup). And VERIFY THE SLOT: key in the Anthropic row, OpenRouter row EMPTY — the dialog has misfiled keys before.
  1. Pin the model to Sonnet (bottom-right; Opus ≈ 5× cost)
  2. Gateway reads ready

Errors: "authentication failed" = wrong slot/bad paste · "no usable credit" = unfunded or different account (key+money+account must match) · mentions "OpenRouter" = trash that entry, select Anthropic, restart

STEP 5

Create the Telegram bot (phone)

  1. Telegram search → @BotFather (verified — clones exist) → send /newbot
  2. Display name = the business brand · username must end in bot
  3. Save the returned token (1234567890:AAE...) — never in screenshots or group chats
  4. Tap START on the new bot — bots can't speak first

Numeric user ID (a number, not the @username): message @userinfobot (exact handle) → Start → copy Id:. Fallback: message your own bot, then open https://api.telegram.org/bot<TOKEN>/getUpdates → find "from":{"id":. Lost the bot? BotFather → /mybots.

STEP 6

Wire Telegram in Hermes

Messaging → Telegram: 1. Bot token → paste 2. Allowed Telegram user IDs → the numeric ID(s), comma-separated 3. Allow all users = false/empty. Always. 4. Home channel ID = same user ID (enables agent-initiated alerts and crons) 5. Save → if the UI shows a stale status, full quit (system tray too) and reopen

STEP 7

First contact

From the phone, message the bot:

Confirm you're connected.
✔ Expect: a reply in Telegram
What AI model are you using?
✔ Expect: it names Sonnet — if it says Opus, go flip the selector

Billing proof: console.anthropic.com → Usage — today's test traffic must appear there. Silent bot + "Connected" status = allowlist miss (numeric ID? saved?).

STEP 8

Deploy the knowledge base files

  1. Create the folder — Mac~/Documents/JARVIS-Knowledge · WindowsDocuments\JARVIS-Knowledge
  2. Copy in the 10 wholesale KB files:
_INDEX map + load order
00 operating doctrine — governs all
01 wholesale fundamentals
02 lead intake & qualification
03 seller communication
04 property analysis & offer
05 contracts & paperwork
06 pipeline & follow-up
07 disposition
08 quick reference
  1. If the files are in Downloads, the agent can do the move itself:
Search my Downloads folder for the wholesale knowledge base .md files (the _INDEX and 00–08 set). List what you find — don't move anything yet.
✔ Expect: it lists the 10 files; verify the names match before the next prompt
Create the folder Documents\JARVIS-Knowledge (or ~/Documents/JARVIS-Knowledge on Mac), move those 10 files into it, then list the folder contents to confirm.
STEP 9

Load + persist the KB

Read every file in [folder path], starting with _INDEX.md, then 00_operating-doctrine.md — the doctrine governs everything else. These files are your permanent knowledge base and source of truth. Add a permanent instruction to your memory: at the start of every session, on any channel, read this folder before doing business tasks. Confirm the instruction is saved.
✔ Expect: confirmation + a memory-update acknowledgment

Verify it actually loaded — ask all three:

Summarize your operating doctrine in 3 bullets.
✔ Expect: no legal/financial advice · no fabricated numbers · escalate probate/title/distress to the operator
What are the four pillars of lead qualification?
✔ Expect: Condition · Motivation · Timeline · Price/Mortgage
Walk me through how you calculate MAO.
✔ Expect: MAO = ARV − repairs − end-buyer profit − assignment fee − closing costs, 70% rule labeled as a convention, and it should say it will NOT produce an offer with missing inputs
STEP 10

Lock the operator's values

The KB ships universal on purpose — these numbers are per-operator (the _INDEX lists them). The agent will refuse to invent them, so give them now:

Lock these operator values into your knowledge permanently — create a file operator-values.md in the knowledge folder with: - Buy areas / markets: [cities, counties, zips] - Property types we buy / avoid: [list] - Target end-buyer profit margin: [X% or $X] - Target assignment fee: [$X] - Default MAO percentage: [e.g. 70%] and closing-cost assumption: [$X or X%] - Repair standards: light $[X]/sqft · medium $[X]/sqft · heavy $[X]/sqft - EMD policy: [amount, holder] - Follow-up cadence overrides: [if any] Confirm the file is saved and read it back to me.
✔ Expect: it writes the file and reads back YOUR numbers
⚠️
Do not skip this. Without operator values the agent answers like a textbook and (correctly) refuses to run offer math.
STEP 11

Run it — the agent is live

Acceptance test — paste a fake lead:

New seller lead: John Smith, 123 Main St. Says the house needs work, tenant stopped paying, wants out fast. Qualify this lead per your SOP and tell me the next action.
✔ Expect: it works the four pillars, tags the situation (tired-landlord, major-repairs...), tiers it, names what's missing, sets ONE next action — and does NOT invent an offer

Daily driver prompts (these run the business day to day):

Give me a pipeline snapshot: count by stage, everything due or overdue, hottest deals, and any record missing a next action.
Draft a follow-up text for [seller] who said they'd think about it — per the seller-communication SOP.
Run the numbers: ARV [$X] from these comps [paste], repairs look [light/medium/heavy], [sqft]. Give me the offer package.

Optional — auto-start so it survives reboots: WindowsAdmin PowerShell → hermes gateway install · Machermes gateway --help → service option. Anytime: hermes gateway status / hermes gateway restart
