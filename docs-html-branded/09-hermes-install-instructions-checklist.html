DOC 09Internal — Generalized For All Installs

Hermes Installation
Instructions & Checklist

Part 1 walks the install step by step. Part 2 is the print-ready per-machine checklist. Mac Terminal & Windows PowerShell.

PART 1

Step-by-Step Instructions

Follow in order. “You” = whoever is at the keyboard.

STEP 1

Open the shell

MacCmd+Space → type terminal → Enter
WindowsStart → type powershell → Enter

STEP 2

Check prerequisites

node --version

python3 --version      (Mac)
python --version       (Windows)

Need Node v18+ and Python 3.10+.

  • Node missing → nodejs.org → LTS installer, defaults (Mac chip: Apple menu → About This Mac)
  • Python missing (Windows) → python.org installer → tick “Add Python to PATH” on the FIRST screen
  • Mac: “command line developer tools” popup → click Install (includes Git, 5–15 min). No popup? xcode-select --install
  • Windows: do NOT pre-install Git — the Hermes installer handles it
STEP 3

Network pre-flight

curl -I https://api.telegram.org
  • HTTP response back → network clear, continue
  • Hangs or redirects → network blocks Telegram → switch to a phone hotspot for the install; fix the network permanently afterward
STEP 4

Run the Hermes installer

  1. Download the Hermes Desktop installer from the standard source and launch it
  2. The “System prerequisites — X of 11 steps” screen appears with a Live Output panel — let it run untouched
  3. Mac: stuck at 0 of 11? The Apple developer-tools dialog is hiding behind your windows — find it, click Install, let it finish; the installer resumes (relaunch if it doesn't within 2 minutes)
  4. Let ALL steps finish, including “Download Hermes Agent” — never cancel mid-way

Install locations: Mac~/.hermes/hermes-agent · WindowsC:\Users\<username>\AppData\Local\hermes\hermes-agent

STEP 5

Verify

⚠️
Close the shell entirely and open a FRESH one — new commands are invisible to old sessions.
hermes --version

Expected: version banner — agent version (0.18+), Python version, project path.

Still “command not found” in a fresh shell? Run the full path — if it works, the install is fine (PATH issue only): - Mac: ~/.hermes/hermes-agent/venv/bin/hermes --version - Windows: ...\hermes-agent\venv\Scripts\hermes --version

STEP 6

First run

hermes gateway

A healthy first run prints the “Hermes Gateway Starting… Messaging platforms + cron scheduler” box. Messages about a missing provider or channels are the setup to-do list, not errors.

STEP 7

Continue setup in the Hermes app

  1. AI provider: API-key path ONLY — “I have an API key” → key goes in the Anthropic row → OpenRouter row must be EMPTY → never click the OAuth sign-in → pin the model to Sonnet
  2. Messaging: bot token + numeric user ID → allowlist filled → allow-all = false → Save
  3. Knowledge base, CRM, and acceptance testing per the Install Cheat Sheet
STEP 8

Make it survive reboots

  • Windowsopen PowerShell as Administrator → hermes gateway install
  • Machermes gateway --help → use the service/install option
  • Reboot test: restart the machine → the agent answers on its channel with no app opened manually
PART 2

Per-Install Checklist

Print or duplicate one per machine. Install is complete only when every box is checked.

Machine:   OS: Mac   Windows   Date:   Installed by:

A. Prerequisites

  • Shell opened (Terminal / PowerShell)
  • node --version → v18+ (installed from nodejs.org if missing)
  • Python 3.10+ confirmed (Windows: “Add Python to PATH” was ticked)
  • Mac only: developer tools installed (popup accepted or xcode-select --install)
  • Windows only: Git NOT pre-installed (installer handles it)
  • Network pre-flight run → Telegram reachable YES / NO → hotspot used if blocked

B. Installation

  • Hermes installer downloaded from standard source
  • Prerequisites phase completed all 11 steps (no cancel/relaunch mid-way)
  • Mac only: developer-tools dialog found and accepted if installer stalled
  • Install completed through “Download Hermes Agent”

C. Verification

  • FRESH shell opened after install
  • hermes --version returns banner — version recorded: ______
  • Version is 0.18+ (if 0.17 on Windows: note flashing-window patch may be needed)
  • hermes gateway first run prints the startup box

D. App-side setup

  • Provider connected via API key — Anthropic row verified · OpenRouter row EMPTY
  • OAuth sign-in NEVER used
  • Model pinned to Sonnet
  • Gateway status reads ready
  • Messaging: token pasted · numeric user ID in allowlist · allow-all = false · saved
  • Round-trip test: message from an allowed phone → bot replies

E. Durability

  • Auto-start installed (Windows: PowerShell as Admin → hermes gateway install / Mac: service option)
  • Reboot test passed (or scheduled: ______)

F. Sign-off

  • All boxes above checked — install COMPLETE
